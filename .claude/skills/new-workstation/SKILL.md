# New workstation

1. Agree on the name with the user: short, plain letters and spaces only (no accents, symbols or slashes), so it works on Windows. Example: "Health", "Clients", "Travel", "Studies".
2. Create the folder at the workspace root with:
   - `CLAUDE.md` with the four sections from the root `CLAUDE.md` (Identity, Resources, Workflow, Editorial Rules). Write them for **this** person, using what `00_Resources/profile.md` says about this area. The Workflow says what "done" looks like and how to check it.
   - `MEMORY.md` with `## Contacts` and `## Key Decisions`.
   - `Resources/` with one starter file the workflow uses (a list, a log or a tracker in markdown), listed in the Resources table.
3. Add a row to the Routing Map in the root `CLAUDE.md`, and a category to the Inbox routing table.
4. Check: re-read the three files and the new Routing Map row. Tell the user in one line what the workstation does and one example of what to ask it.

## Ideas, by what people often need

| Workstation | For |
| :---- | :---- |
| Work or Clients | Projects, deliverables, client follow-ups, proposals |
| Career | CV, interviews, goals, achievements log |
| Health | Appointments, exams, medication, routines |
| Home | Maintenance, repairs, purchases, contractors |
| Travel | Trip plans, bookings, packing lists, documents |
| Pets | Vet, vaccines, food, routines |
| Studies | Courses, notes, deadlines, study plan |
| Kitchen | Meal plans, grocery lists, recipes |
| Decisions | Important choices, with a date to review how they turned out |
| Side Business | Products, customers, orders, finances of a small business |
