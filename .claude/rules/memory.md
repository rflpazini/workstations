# Memory

- When the user says "remember this", "don't forget", "lembra que" or anything like it, save it right away and confirm in one line where you saved it.
- Where it goes: a fact about one area goes to that workstation's `MEMORY.md`; a fact that spans areas goes to the root `MEMORY.md`. A rule about how you should behave ("always...", "never...") goes to `00_Resources/codex.md`.
- Write facts in the user's language, one line each, with the date when it matters.
- Update a fact in place when it changes; don't keep contradicting lines.
- Your own built-in memory does not travel between devices. Everything worth keeping goes into these files.
